## Start here

- **[lookbk-skills](https://github.com/lookbkdev/lookbk-skills)**: eight free skills (MIT) for title videos, slide decks, link-preview images, diagrams and landing pages. Install with `npx skills add lookbkdev/lookbk-skills`.
- **[awesome-ai-motion-videos](https://github.com/lookbkdev/awesome-ai-motion-videos)**: motion graphics, launch films and 3D scenes that AI coding models made in code, credited and with prompts.
- **[lookbk.dev](https://lookbk.dev/?utm_source=github&utm_medium=org-profile&utm_campaign=org-readme)**: the full catalog of 200+ skills, each with a live preview. New skills every Tuesday.
